简迹 - 隐私政策

生效日期：2026年4月30日

最近更新日期：2026年9月15日

🔒 隐私承诺
简迹是一款专注于隐私保护的笔记应用。你的数据只属于你，完全存储在本地设备上，永远不会上传到任何服务器。

1. 信息存储与处理

1.1 本地存储
本应用采用纯本地存储架构。所有笔记内容、标签、情感分析数据等均存储在您的设备本地，不会上传至任何云端服务器。

1.2 数据内容
应用会处理并存储以下数据（仅限本地）：

  • 您创建的笔记内容（标题、正文）
  • AI 生成的标签和主题分类
  • 情感分析结果
  • 笔记的创建、修改、归档时间
  • 应用设置和偏好

2. 生物识别功能

2.1 Face ID / Touch ID
本应用提供可选的生物识别锁定功能，用于保护您的私密笔记。

2.2 生物数据处理

  • 生物识别认证由系统原生提供（Apple Face ID / Touch ID）
  • 应用不会收集、存储或传输您的生物特征数据
  • 生物识别验证完全在设备安全芯片中完成
  • 应用仅接收验证结果（成功/失败），不接触原始生物数据

3. PIN 码保护

3.1 PIN 码存储
如果您选择设置 PIN 码：

  • PIN 码经过加密后存储在设备本地
  • 不会上传至任何服务器
  • 遗失 PIN 码可通过生物识别重置

4. 信息收集声明

本应用不会收集以下信息：

  • 个人身份信息（姓名、手机号、邮箱等）
  • 设备信息（设备型号、系统版本、唯一标识符等）
  • 位置信息
  • 通讯录、照片等系统数据
  • 使用行为数据

5. 第三方服务

本应用不接入任何第三方服务：

  • ❌ 无第三方统计 SDK
  • ❌ 无广告 SDK
  • ❌ 无第三方登录服务
  • ❌ 无数据分析和追踪
  • ❌ 不与任何第三方共享信息

6. 数据安全

6.1 安全措施

  • 所有数据存储在设备本地沙盒中
  • 敏感笔记可使用生物识别或 PIN 码加密保护
  • 应用使用 iOS 系统级安全机制

6.2 数据删除
您可以随时通过以下方式删除数据：

  • 删除单篇笔记（进入回收站，30 天后自动永久删除）
  • 清空回收站（立即永久删除）
  • 卸载应用（所有本地数据将被清除）

7. 数据备份与恢复

7.1 本地备份
应用提供 JSON 格式的本地备份功能：

  • 备份文件存储在您的设备上
  • 您可以选择备份到 iCloud Drive（需系统权限）
  • 备份文件由您完全控制

7.2 iCloud 备份（可选）
如果您启用了系统级 iCloud 备份，应用数据可能会包含在 iCloud 备份中。这由您的系统设置控制，应用本身不主动上传数据。

8. 儿童隐私

本应用面向所有年龄段用户。由于应用不收集任何个人信息，因此不存在儿童隐私泄露风险。家长可以放心让孩子使用。

9. 隐私政策更新

我们可能会不时更新本隐私政策。更新后的政策将在应用内公布，建议您定期查看。

如有重大变更，我们会在应用更新时提醒您审阅新的隐私政策。

10. 您的权利

您对您的数据拥有完全控制权：

  • ✅ 随时查看您的所有数据
  • ✅ 随时修改或删除任何笔记
  • ✅ 随时导出您的数据
  • ✅ 随时删除应用和数据
  • ✅ 随时开启或关闭生物识别保护
